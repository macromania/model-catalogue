# Product

## Register

product

## Platform

web

## Users

A team building an Azure-first product and comparing AI model specifications.

## Product Purpose

Browse underlying models rather than repeated provider offerings, with explicit Azure support evidence and Azure-first limits/prices. Provider listings remain detail metadata. Seed the local or cloud database, then inspect it without contacting upstream services from the API or browser.

## Positioning

A small, inspectable Azure-first model catalogue rather than a provider gateway.

## Brand Personality

Plain, factual, low-fidelity.

## Anti-references

No marketing landing page, decorative model cards, authentication screens, or invented benchmark scores.

## Design Principles

Show each identified model once. Make Azure support and source confidence explicit. Keep provider differences in details, not duplicate list rows. Show unknown values honestly and use familiar tables and form controls.

## Accessibility & Inclusion

Implementation defaults include keyboard navigation, visible focus, readable contrast, labeled controls, and reduced motion. No additional user-specific requirements were supplied.
