# Model catalogue SPA

React, TypeScript and Vite, organized into catalogue, model-detail and comparison slices. Each slice owns its components, styles and relevant tests. `src/App.tsx` composes the surface; `src/shared/` contains small shared contracts and primitives.

Use `make dev-ui`, `make test`, and `make verify` from the repository root. See the [project README](../README.md) for the kind stack, seeding, port configuration and public Azure deployment boundaries.
